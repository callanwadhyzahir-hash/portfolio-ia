# Project Identity

Project Name:
Wadhy Portfolio

Purpose:

This is not a template portfolio.

This portfolio represents the technical identity of its creator.

Every design decision,
every animation,
every interaction,
every component
must communicate professionalism,
engineering quality,
and passion for Artificial Intelligence.

The portfolio should feel like a premium software product.

Not like a school assignment.

---

# Engineering Principles

Write code as if this project will be maintained for 10 years.

Prioritize:

- readability
- modularity
- scalability
- performance
- accessibility
- SEO
- maintainability

Never sacrifice architecture for speed.

# Component Rules

One component = one responsibility.

Avoid files larger than 250 lines.

Extract reusable logic.

Avoid duplicated JSX.

Prefer composition over inheritance.

---

# Code Style

Prefer const.

Avoid any.

Strong typing.

Descriptive variable names.

No magic numbers.

No nested ternary operators.

No duplicated logic.

No unnecessary comments.

Comments should explain WHY.

Not WHAT.

---

# UI Rules

Minimalism.

Generous spacing.

High readability.

Responsive first.

Smooth animations.

Consistent color palette.

Consistent typography.

Dark Mode by default.

No visual clutter.

---

# Accessibility

Semantic HTML.

Keyboard navigation.

ARIA labels.

Color contrast.

Alt text.

# Performance

Lazy Loading.

Dynamic imports.

Image optimization.

No unnecessary re-renders.

Server Components first.

Optimize Core Web Vitals.

# Git Workflow

Small commits.

Atomic commits.

Meaningful commit messages.

Never commit broken code.
